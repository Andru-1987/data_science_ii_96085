# Data Science II - Temario y Recursos

Bienvenido al repositorio del Bootcamp de Data Science. Este repositorio contiene el material, apuntes, ejercicios y proyectos desarrollados a lo largo del curso. El temario esta disenado para llevar a los estudiantes desde los fundamentos de bases de datos hasta modelos avanzados de Machine Learning, culminando en un Datathon final.

---

## Temario Completo


### Modulo 1: Bases de Datos y Aplicaciones
Conceptos fundamentales de bases de datos relacionales y su aplicacion en proyectos de datos.

---

### Modulo 2: SQL y Adquisicion de Datos
- 2.1 Introduccion
- 2.2 Repositorios y fuentes de datos
- 2.3 Introduccion a SQL
- 2.4 Sentencias Basicas de SQL
- 2.6 Recursos complementarios
- 2.7 Glosario

---

### Modulo 3: SQL Avanzado y Otros Datos
Consultas complejas, subconsultas, joins avanzados y manejo de diferentes tipos de datos.

---

### Modulo 4: APIs y Data Wrangling
Consumo de APIs para extraccion de datos y tecnicas de limpieza y transformacion (Data Wrangling).

---

### Modulo 5: Optimizacion de Datos Limpios
Estrategias para optimizar y preparar datasets limpios y eficientes para analisis.

---

### Modulo 6: EDA y Visualizacion de Datos
Analisis Exploratorio de Datos (EDA) y creacion de visualizaciones efectivas para extraer insights.

---

### Modulo 7: Storytelling y Visualizacion GIS
Narracion de historias con datos y visualizacion geoespacial usando Sistemas de Informacion Geografica (GIS).

---

### Modulo 8: Analisis Uni y Bivariado
Metodos estadisticos para analizar una variable (univariado) y la relacion entre dos variables (bivariado).

---

### Modulo 9: Analisis Multivariado
Tecnicas para explorar y modelar relaciones entre multiples variables simultaneamente.

---

### Modulo 10: ML y Mejora de Modelos
Introduccion al Machine Learning y primeros pasos en la mejora del rendimiento de modelos.

---

### Modulo 11: Clasificacion y Regresion
Modelos supervisados: algoritmos de clasificacion y regresion para prediccion.

---

### Modulo 12: Reduccion y Agrupacion
Tecnicas no supervisadas como reduccion de dimensionalidad y clustering (agrupacion).

---

### Modulo 13: Evaluacion de Clasificacion
Metricas y tecnicas para evaluar el desempeno de modelos de clasificacion.

---

### Modulo 14: Validacion y Problemas en ML
Validacion de modelos, overfitting, underfitting y otros desafios comunes en Machine Learning.

---

### Modulo 15: Modelos de Ensamble y Mejora
Uso de ensambles (Bagging, Boosting, Stacking) para mejorar la precision y robustez de los modelos.

---

### Modulo 16: Datathon en Data Science
Proyecto final integrador donde se aplican todos los conocimientos adquiridos en un desafio practico de datos.

---

## Tecnologias y Herramientas

- Lenguajes: Python, SQL
- Librerias: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SQLAlchemy, Requests, Folium, entre otras.
- Entornos: Jupyter Notebooks, VS Code, Google Colab.
